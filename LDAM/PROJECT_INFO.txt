🔌 API ENDPOINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
GET  /              Main web page
GET  /api/data      Get sensor data (JSON)
GET  /api/ports     Get available serial ports
POST /api/connect   Connect to serial device
POST /api/disconnect Disconnect from device

🔧 REQUIREMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Software:
  - Python 3.7+
  - Flask 3.0.0
  - pyserial 3.5
  - Modern web browser

Hardware:
  - Arduino or ESP32
  - Temperature sensor (MLX90614 or similar)
  - GPS module (NEO-6M or similar)
  - USB cable

Data Format (JSON via serial at 115200 baud):
  {"temperature": 38.5, "latitude": 12.34, "longitude": 56.78}
